\section*{Extracto}
El presente informe tiene como objetivo presentar un análisis detallado del Sistema Operativo de Robótica (ROS 2), explorando sus características, arquitectura y aplicaciones en el ámbito de la robótica. Se abordarán aspectos clave como la comunicación entre nodos, la gestión de sensores y actuadores, y la integración con hardware específico. Además, se discutirán las ventajas y desafíos asociados con el uso de ROS 2 en proyectos de investigación y desarrollo.

\subsection{Glosario de términos}
Terminología utilizada en el informe:
\begin{itemize}
    \item \textbf{ROS 2:} Robot Operating System 2, un sistema operativo de código abierto para la robótica.
    \item \textbf{Nodo:} Una unidad de ejecución en ROS 2 que realiza tareas específicas y se comunica con otros nodos.
